# Phil's Refund Rush

Steam refunds any game played for under 2 hours. Phil plays every game for exactly 1:59:59.

**Play:** https://zeredbaron.github.io/phil-refund-rush/

- Pick a game with `1` `2` `3` (or tap).
- Press `Space` (or the REFUND button) as close to 2:00:00 as you dare.
- Hold `Shift` to fast-forward.

`classic.html` is the original four-slot version.
